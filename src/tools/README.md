# Tools

Tool implementations organized by category:

- `agents/` - Agent management (create, list, modify, delete, clone, etc.)
- `memory/` - Memory block operations
- `passages/` - Passage management
- `tools/` - Tool attachment and management
- `mcp/` - MCP server integration
- `models/` - Model listing (LLM and embedding models)

All tools return structured responses matching their output schemas.
